Foundations

Typography

Iowa brand fonts reflect our personality and reinforce our identity. Together, they create a cohesive typography system that supports brand recognition across print and digital communications.

Use fonts intentionally

Each font serves a distinct purpose within our typography system. Understanding these roles helps you use fonts consistently across different applications. Many brand templates and tools already include approved font styles to make this easier.

  • Special Gothic Condensed: promotional, bold, attention-getting
  • Roboto: functional, everyday, readable
  • Zilla Slab: warm, editorial, publication-like
  • Lora: formal, traditional, ceremonial or institutional

Before you start

Only approved brand fonts are permitted in marketing and communications materials.

To install these fonts on university computers, open the Self-Service application on your desktop. Once the app has launched, search “University Brand Fonts” and click “Install.” Once complete, fonts should appear in your font dropdown menus. Downloads of each font are also provided below if needed.

Special Gothic Condensed

Special Gothic Condensed is a tall, condensed typeface that creates strong visual presence. Its bold character adds emphasis and impact, helping important messages and information stand out.

Get Special Gothic Condensed

Guidance

  • Keep headlines and display text concise. Never use Special Gothic Condensed for body copy, long passages, or text that requires sustained reading.
  • Create emphasis through size, weight, and letter case. Don’t add artificial italics, stretch, skew, or further condense the letterforms.
  • Use sentence case for headlines. Only use all caps for short headlines or display text of 1–5 words when you need to create emphasis. Legibility is compromised if all caps are applied to long headlines and display text.

Roboto

Roboto is our functional typeface. It is clean, neutral, and easy to read across a wide range of sizes. It offers a broad range of weights and styles that makes it highly versatile across print and digital communications.

Download Roboto

Guidance

  • Use Roboto as the standard for body text and functional information. Don’t use Special Gothic Condensed or Zilla for body text.
  • Use italics for emphasis and as outlined in our editorial style guide. Don’t use italics decoratively or in place of clearer writing.

Zilla Slab

Zilla Slab adds warmth and contrast to the typography system. Its distinctive serif letterforms are well suited for editorial communications, while offering flexibility to lead or support other brand fonts.

Guidance

  • Don’t use Zilla Slab for body text. Its heavier serifs can make longer passages harder to read.

Lora

Lora is our more traditional serif typeface reserved for formal and ceremonial communications. Its refined letterforms give these materials a polished appearance while maintaining strong readability.

Download Lora

Guidance

  • Reserve Lora for communications with a clear formal or ceremonial purpose. Don’t use it as decoration or to make routine pieces feel formal.
  • Use Lora for prominent titles and shorter passages of text. Keep longer body text in Roboto.
  • Don’t use Lora and Zilla Slab in the same piece. Both are distinctive serifs, and together they compete for attention.
  • Use italics to add contrast or emphasis to short passages and callouts.

Font Awesome icons

Font Awesome provides small, functional icons that support actions, information, and interface states. Use these icons minimally. For more expressive applications, use Iowa Brand Icons.

Use Font Awesome

View all suggested icons

When to use

  • Interface and navigation elements
  • Social media platform icons
  • Directional arrows and wayfinding cues
  • Action icons paired with buttons or links

Guidance

  • Choose either Solid or Regular icons based on the level of emphasis needed and use that style consistently. Don’t use Thin, Light, Duotone, Sharp, animated, or other specialty styles.
  • Keep icons smaller and less prominent than the text they support. As a starting point, size an icon to about 75% of the text line height, then adjust for visual balance.
  • Pair icons with visible text unless their meaning is widely understood. When text already explains the icon, hide it from screen readers to avoid repetition. When an icon appears alone, provide an accessible name and add a tooltip when helpful.
  • Don’t use Font Awesome as a substitute for Iowa brand icons in larger-scale or expressive applications.

Letter case guidelines

Use sentence case as the standard: For optimal legibility, always use sentence case as the default for body text, full sentences, longer headlines and subheads, navigation, instructions, descriptions, and supporting content.

Limit uppercase (or all caps): Only use uppercase when text is short (1–5 words), and the goal is to signal, label, emphasize, or create visual impact. While uppercase can add boldness to messaging and draw attention to key moments, it becomes harder to read and less effective when overused.

Never use uppercase for paragraphs and body text content intended for sustained reading or multiple elements within the same composition.

Only use uppercase for short, high-impact text, such as:

  • Display headlines or short statements intended to create a bold visual moment
  • Eyebrows, kickers, labels, tags, and badges
  • Short calls to action
  • Dates, times, or other concise informational callouts
  • Environmental graphics, merchandise, and other applications where typography functions as a prominent visual element

The University of Iowa uses predominantly AP style across our communication. Consult the Editorial Style Guide for additional instructions for text formatting, capitalization, and punctuation.

See editorial style guide

Uppercase in digital applications

For digital use, apply uppercase through CSS. This allows uppercase to function as a visual treatment without changing the underlying content. Siteimprove R72 evaluates paragraph-role elements, so CSS applied on a heading, button, tag, or similar element does not trigger the rule. Letters should only be typed as capitals for acronyms.
