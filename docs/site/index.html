Getting Started

Introduction

UIDS Docs 5.0.0-alpha.1

The UIDS component library is a central repository of brand-approved components for websites and digital experiences, whatever the platform or content management system. Every component uses the official brand colors, fonts, and graphic elements. Read more on the Brand Manual website.

Add the fonts

The UIDS stylesheets don't load fonts. Add these lines to the <head> of every page.

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css" crossorigin="anonymous" referrerpolicy="no-referrer" />
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
<link href="https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,300;0,400;0,500;0,700;0,900;1,400&display=swap" rel="stylesheet" />
<link href="https://fonts.googleapis.com/css2?family=Zilla+Slab:wght@300;400;500;600;700&display=swap" rel="stylesheet" />
<link href="https://fonts.googleapis.com/css2?family=Antonio:wght@100;300;700&display=swap" rel="stylesheet" />
<link href="https://fonts.googleapis.com/css2?family=Lora&display=swap" rel="stylesheet" />

Choose how to load UIDS

OptionUse it forTrade-off
Link the hosted CSSA page or CMS theme with no build stepNo install. You move to a new version by changing the URL.
Install a releaseA project with a JavaScript buildThe version is pinned in package.json. Your build tool must resolve package exports.
Use the tokensYour own components, in UIDS colors, type, and spacingNo UIDS component styles.

Link the hosted CSS

We publish each release's CSS at a URL that includes the version. Link the full stylesheet, or the core styles plus one file for each component you use.

<!-- Everything -->
<link rel="stylesheet" href="https://uids.brand.uiowa.edu/docs/v5.0.0-alpha.1/dist/css/uids.css">

<!-- Or the core styles plus the components you use -->
<link rel="stylesheet" href="https://uids.brand.uiowa.edu/docs/v5.0.0-alpha.1/dist/css/uids-core.css">
<link rel="stylesheet" href="https://uids.brand.uiowa.edu/docs/v5.0.0-alpha.1/dist/css/components/button.css">

Component files are named after the component, such as accordion.css, alert.css, and card.css. Storybook shows the markup each one expects.

Install a release

Each GitHub release has a package attached. Add it to your dependencies by its URL. The npm package named uids is not this one.

"dependencies": {
  "@uiowa/uids": "https://github.com/uiowa/uids/releases/download/v5.0.0-alpha.1/uids-5.0.0-alpha.1.tgz"
}

Then import what you need:

ImportContents
@uiowa/uids/uids.cssThe full stylesheet
@uiowa/uids/uids-core.cssReset, base HTML, and custom properties
@uiowa/uids/tokens.cssCustom properties only
@uiowa/uids/components/<name>.cssOne component
@uiowa/uids/scss/<path>Sass source
@uiowa/uids/tokens/<tier>/<group>.jsonToken source

Use the tokens

tokens.css defines each UIDS token as a CSS custom property named after its path, such as --uiowa-color-link-default. Load it from either source above. Colors and Typography list the tokens.

The token source files are JSON in the DTCG format.
