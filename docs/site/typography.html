Foundations

Typography

UIDS Docs 5.0.0-alpha.1Adapted from the Foundations v0.1 draft

Iowa brand fonts reflect our personality and help reinforce our identity. Each typeface has a distinct purpose, and together they create a cohesive typography system that supports brand recognition across print and digital applications.

Choose typefaces by purpose and tone

Each typeface brings a different character to the system. Choose based on the kind of communication you’re creating and the tone you want to set.

  • Antonio: promotional, bold, attention-getting
  • Roboto: functional, everyday, readable
  • Zilla Slab: warm, editorial, publication-like
  • Lora: formal, traditional, ceremonial or institutional

Use fonts intentionally

Each font within our system serves a specific function and purpose to create clear hierarchy, consistent tone, and readability. Use each font as outlined to ensure our audiences have a consistent experience across all Iowa communications.

Antonio

Antonio is a tall, condensed typeface that creates strong visual presence. It works best at larger sizes and with concise messages, making it especially effective for promotional communication, callouts, and other moments that need emphasis.

When to use

  • Short headlines and titles
  • Callouts and key messages
  • Facts, rankings, and statistics
  • Other concise text that needs to stand out

Antonio Weights

  • Thin (100)
  • Light (300)
  • Bold (700)

Guidance

  • Keep headlines and display text short. Never use Antonio for body copy, long passages, or text that requires sustained reading.
  • Create emphasis through scale, weight, and case. Don’t add artificial italics, stretch, skew, or further condense the letterforms.
  • Use sentence case for headlines. Only use all caps for short headlines or display text of 3–4 words when you need to create emphasis. Legibility is compromised if all caps are applied to long headlines and display text.

Roboto

Roboto is the functional, everyday typeface in the system. It is clean, neutral, and easy to read across a wide range of sizes, with a broad range of weights and styles that make it useful for body text, labels, and everyday communication across formats.

When to use

  • Body text and long passages
  • Captions and explanatory text
  • Interface labels, controls, and forms
  • Email and everyday documents
  • Tables, labels, and dense layouts

Roboto Weights

  • Thin and Thin Italic
  • Light and Light Italic
  • Regular and Italic
  • Medium and Medium Italic
  • Bold and Bold Italic
  • Black and Black Italic

Recommended weights: use Regular (400) for body text because it provides the best readability. For headings, use Medium (500).

Guidance

  • Use Roboto for body text and functional information. Don’t use Antonio or Zilla for body text.
  • Use italics for emphasis and as outlined in our editorial style guide. Don’t use italics decoratively or in place of clearer writing.
  • Keep body text at a readable size with sufficient line spacing. Don’t reduce type size or spacing simply to make content fit.

Zilla Slab

Zilla Slab adds warmth and contrast to the typography system. It is especially well suited to editorial uses such as feature stories, profiles, and publication-style content, but it can also be used more broadly when that tone is appropriate.

When to use

  • Headlines for feature stories and profiles
  • Editorial titles and section openers
  • Introductory or lead-in text
  • Pull quotes
  • Select section labels
  • Other moments where a warmer, more editorial tone is useful

Zilla Slab Weights

  • Light and Light Italic
  • Regular and Italic
  • Medium and Medium Italic
  • Semibold and Semibold Italic
  • Bold and Bold Italic

Recommended weights: Regular (400) is for body text because it provides the best readability. For headings or titles, use Semibold (600).

Guidance

  • Zilla may lead in editorial applications or work in a supporting role within other communications.
  • When another typeface leads, use Zilla to create useful contrast rather than competing for equal emphasis.
  • Use the semibold weight of Zilla to achieve the best balance with our other fonts.
  • Don’t use Zilla Slab as the dominant typeface.

Lora

Lora is our formal serif font. It is reserved for ceremonial communications and materials when a more traditional tone is appropriate. Its refined letterforms remain highly legible and give ceremonial materials a polished appearance.

When to use

  • Formal or ceremonial headlines and titles
  • Invitations and event titles
  • Awards, certificates, and recognition materials
  • Commencement and other ceremonial communications
  • Longer formal text when a more traditional tone is appropriate

Lora Weights

  • Regular and Italic
  • Medium and Medium Italic
  • SemiBold and SemiBold Italic
  • Bold and Bold Italic

Recommended weights: Regular (400) is for body text because it provides the best readability. For headings or titles, use Bold (700).

Guidance

  • Reserve Lora for communications with a clear formal or ceremonial purpose. Don’t use it to add formality to routine communications.
  • It may be used for prominent titles as well as sustained reading in formal or ceremonial work.
  • Keep usage restrained. Lora should add formality without feeling ornate or decorative.
  • Don’t use Lora and Zilla Slab in the same composition. Both have distinct serif characteristics and using them together creates unnecessary visual competition.
  • Only use italics for emphasis, citations, or titles within ceremonial text; keep body text in Lora regular style for sustained reading.

Font Awesome

Font Awesome provides small, functional icons that support actions, information, and interface states. Use these icons minimally. For more expressive applications, use Iowa Brand Icons.

When to use

  • Interface and navigation elements
  • Social media platform icons
  • Directional arrows and wayfinding cues
  • Action icons paired with buttons or links

Guidance

  • Choose either Solid or Regular icons based on the level of emphasis needed and use that style consistently. Don’t use Thin, Light, Duotone, Sharp, animated, or other specialty styles.
  • Keep icons smaller and less prominent than the text they support. As a starting point, size an icon to about 75% of the text line height, then adjust for visual balance.
  • Pair icons with visible text unless their meaning is widely understood. When text already explains the icon, hide it from screen readers to avoid repetition. When an icon appears alone, provide an accessible name and add a tooltip when helpful.
  • Don’t use Font Awesome as a substitute for Iowa brand icons in larger-scale or expressive applications.

Brand recommendation for uppercase

For optimal legibility, always use sentence case as the default for body text, full sentences, longer headlines and subheads, navigation, instructions, descriptions, and supporting content.

Limit uppercase for when text is short (1-5 words), and the role is to signal, label, emphasize, or create visual impact. While uppercase can add boldness to messaging and draw attention to key moments, it becomes harder to read and less effective when overused.

Never use uppercase for paragraphs and body text content intended for sustained reading or for multiple elements within the same composition.

Use uppercase for short, high-impact text such as

  • Display headlines or short statements intended to create a bold visual moment
  • Eyebrows, kickers, labels, tags, and badges
  • Short calls to action
  • Dates, times, or other concise informational callouts
  • Environmental graphics, merchandise, and other applications where typography functions as a prominent visual element

For digital use, apply uppercase through CSS. This allows uppercase to function as a visual treatment without changing the underlying content. Siteimprove R72 evaluates paragraph-role elements, so CSS applied on a heading, button, tag, or similar element does not trigger the rule. Letters should only be typed as capitals for acronyms.
