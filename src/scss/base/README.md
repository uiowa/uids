# Base Design Tokens

**SOURCE OF TRUTH**

This folder contains the **source of truth** for all design tokens.

- **`_tokens.scss`**: This file defines the token values (colors, spacing, etc.).

## How it's used
1.  Edit `_tokens.scss`.
2.  Run `npm run tokens:export`.
3.  The generated `design-tokens/tokens.json` is used by the Figma plugin.
